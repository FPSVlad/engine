# Complete Game Creation Kit (NES / Famicom)

A self-contained starter kit for building NES games with a high-level script language that compiles to bytecode interpreted by a 6502 engine kernel.

## Quick start

```bash
make
```

Output ROM: `game.nes`

## Project layout

- `asm/kernel.asm` — fixed-bank engine kernel, NMI/IRQ handlers, sprite/OAM manager, script VM, basic physics/collision/audio hooks.
- `asm/generated_game.asm` — auto-generated bytecode stream from `scripts/game.script`.
- `asm/game_data.asm` — level/map/music/sfx/demo data.
- `tools/script_compiler.py` — high-level script compiler.
- `nes_mmc1.cfg` — ld65 linker config for MMC1-like layout.
- `Makefile`, `build.bat` — build entry points.
